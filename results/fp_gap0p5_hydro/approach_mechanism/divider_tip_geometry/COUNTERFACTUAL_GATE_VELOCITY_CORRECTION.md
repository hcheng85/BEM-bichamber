# Correction: counterfactual tangent-angle velocity

## What was corrected

The original one-sided reduced drift evaluated the angular rate at the trial
heading but retained the tangent-angle velocity from the observed trajectory.
That mixes two different instantaneous states. The corrected calculation uses
the translation generated by each counterfactual heading:

\[
 \mathbf v_{out/in}(\theta)=\mathbf e(\theta)
   +\mathbf U_{direct}(\theta)+\mathbf U_{BEM}(\theta),
\]

and then evaluates

\[
 \dot\alpha_{out/in}=\nabla_{\mathbf x}\alpha\cdot
                      \mathbf v_{out/in}.
\]

Consequently,

\[
 \mu^{upper}_{out/in}=s\,\Omega_{out/in}
                       -\dot\alpha_{+,out/in},
\qquad
 \mu^{lower}_{out/in}=\dot\alpha_{-,out/in}
                       -s\,\Omega_{out/in},
\]

where \(s=+1\) in the left chamber and \(-1\) in the right chamber. Both
angular and translational quantities now come from the same frozen microscopic
configuration and the same trial focal heading.

Only the class frequencies, angular-entry associations, and prespecified
matched spatial-crossing associations were recomputed. The original tables are
unchanged and remain the explicit comparison baseline.

## Production-override consistency

`focal_replay` follows the production sequence in
`BEM_bichamber_parallel_instance.py`:

1. calculate self-propulsion plus direct and BEM translation;
2. test one-step solid-segment crossing and the componentwise speed safeguard;
3. if either triggers, replace translation by self-propulsion
   \(\mathbf v=\mathbf e(\theta)\);
4. remove direct and BEM angular torques and retain clipped wall plus social
   torque.

The corrected \(\dot\alpha\) is evaluated **after** this replay logic, so an
override would use the overridden translation. In the actual corrected dataset,
none of the 20,048 valid counterfactual trial sides across both epsilon values
activated either override. Thus the numerical correction is not confounded by
collision handling, while remaining consistent with it.

## Numerical effect on the reduced drift

The trial-specific and observed gate velocities are not identical: at
\(\epsilon=10^{-3}\), the median signed change in \(\dot\alpha\) is 0.00586,
the 95th percentile of its absolute change is 1.076, and the maximum is 3.035.
Nevertheless, most points are well inside the same drift quadrant.

At \(\epsilon=10^{-3}\), 99 of 5,012 valid tip evaluations (1.98%) change
class. The principal transitions are:

| old -> corrected | count |
|---|---:|
| deflection -> pinning | 15 |
| pinning -> deflection | 30 |
| pinning -> transmission | 9 |
| transmission -> deflection | 5 |
| transmission -> pinning | 40 |

The corrected frequencies are:

| class | original | corrected | corrected seed-bootstrap 95% interval |
|---|---:|---:|---:|
| deflection | 0.4501 | 0.4541 | [0.4343, 0.4741] |
| pinning | 0.0160 | 0.0192 | [0.0141, 0.0250] |
| transmission | 0.5339 | 0.5267 | [0.5076, 0.5461] |

Pinning remains rare. It is almost identical in event and control snapshots:
1.913% versus 1.918%, respectively.

## Corrected prospective associations

### Angular entry

For configurations initially outside the selected tangent, the corrected
transmission/pinning class continues to predict angular entry:

- A-2, 0.2 window: unadjusted seed-mean risk difference 0.254
  [0.159, 0.361], compared with 0.274 originally.
- A-2, 0.5 window: 0.232 [0.140, 0.329], compared with 0.244 originally.
- A-0.5, 0.5 window: 0.215 [0.117, 0.310] unadjusted and 0.161
  [0.0175, 0.318] after the same angular-error/divider-distance matching.

The correction slightly changes effect sizes but preserves the angular-entry
conclusion.

### Spatial crossing

At A-0.5, the corrected geometry-matched analysis retains 63 pairs. The
matching overlap remains weak (mean standardized distance 1.20):

- focal-fish crossing within 0.5: risk difference 0.158
  [-0.0105, 0.339];
- any-fish crossing within 0.5: 0.0897 [-0.131, 0.306].

Both intervals still include zero. At A-0.2, the matched results are unchanged:
focal crossing within 0.2 is 0.244 [0.044, 0.467] and any-fish crossing is
0.333 [0.111, 0.567], based on only 22 poorly overlapping pairs (mean
standardized distance 1.38). The event/control rematch likewise remains 0.191
[0.020, 0.392] for the combined access class and exactly zero for pinning.
These late associations therefore retain the original commitment-versus-cause
qualification.

## Does the scientific verdict change?

**No.** The corrected calculation is the appropriate reduced drift and should
replace the original drift numerically, but it strengthens neither a stable
pinning mechanism nor independent early prediction of chamber crossing.

The defensible conclusions remain:

1. The rounded-tip ray switch is geometrically exact and supplies an
   instantaneous angular transmission condition.
2. Stable pinning is rare (now 1.92% rather than 1.60%) and is not enriched in
   event snapshots.
3. The one-sided class predicts angular-corridor entry.
4. Spatial crossing is not established at A-0.5 after geometry matching; the
   positive A-0.2 association remains too late and too poorly matched to
   identify initiation.
5. A static angular potential is still not justified. Any future reduced model
   would require a moving corridor and dynamic non-wall terms.
